Bergamo
the memory of places

A widespread museum for a collective memory between Fascism, Nazi occupation and the Resistance

The project

"Bergamo, the memory of places" is a digital project created to enhance and make accessible historical memory sites across the territory. Through a path that combines physical space and digital content, the project allows visitors to rediscover monuments, buildings and places that in the past were linked to Fascism.

The website presents an itinerary composed of several stops, each identified by a QR code placed at the real location. By scanning the code, users can access information, images and insights that help understand the historical and symbolic value of each place, transforming a simple visit into an experience of conscious knowledge.
